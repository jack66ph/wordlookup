# 教育部國語辭典純前端查詢系統

一個專為臺灣正體中文打造的純前端國語字詞查詢網頁。完全不需要任何後端伺服器，雙擊即可在任何瀏覽器直接開啟使用。

---

## 📐 字體與介面規格

嚴格落實指定字型與字體大小規格：
- **顯示字型**：全站統一採用**標楷體**（`DFKai-SB` / `標楷體` / `BiauKai` / `KaiTi`）
- **輸入文字方塊**：`20 點大小 (20pt)`
- **查詢結果詞語展示**：`80 點大字體 (80pt)`
- **詞語解釋文字**：`20 點正常字體 (20pt)`

---

## 🏛️ 資料來源與公信力

- **資料庫核心**：串接中華民國教育部《國語辭典簡編本》與《重編國語辭典修訂本》資料庫（經由萌典 MoEDict 開放 API 提供，依創用 CC-姓名標示-禁止改作 3.0 臺灣授權）。
- **官方辭典直達**：頁面提供一鍵直達教育部《國語辭典簡編本》官方網站與《重編國語辭典修訂本》官方網站的專屬檢索捷徑。

---

## ✨ 主要特色功能

1. **純前端架構**：
   - 單一 `index.html` 檔案，無須安裝 Node.js、Python 或任何後端伺服器，隨開即用。
2. **多音字 / 破音字切換**：
   - 若查詢之詞彙或單字具有多種讀音，自動生成切換標籤，清楚對應不同讀音之解釋。
3. **單字部首與筆畫**：
   - 查詢單字時，自動解析並展示「部首」、「總筆畫數」與「部首外筆畫數」。
4. **完整辭典欄位**：
   - 包含詞性標籤（如名、動、形）、釋義內文（20pt）、例句說明、典故引文出處、相似詞與相反詞。
5. **語音朗讀**：
   - 整合瀏覽器 Web Speech API 臺灣國語語音發音（`zh-TW`），一鍵聆聽字詞發音。
6. **智慧容錯與單字拆解**：
   - 內建正俗體字自動容錯轉換（如「台」與「臺」自動備援嘗試）。
   - 若查詢之長詞在辭典中未收錄，自動提供組成單字之分拆推薦按鈕。
7. **學習單與字卡列印**：
   - 內建列印專用樣式（Print CSS），點擊「列印字卡」即可輸出乾淨無干擾的 80pt 大字體與 20pt 釋義字卡。
8. **歷史紀錄與網址分享**：
   - 自動保存最近查詢紀錄於瀏覽器 LocalStorage。
   - 支援網址參數檢索（例如 `index.html?q=學習`），方便直接加入書籤或分享。

---

## 🚀 使用方法

- **方法一（最簡單）**：
  直接在檔案總管中，對 `index.html` 點擊兩下（或按滑鼠右鍵選擇用 Chrome、Edge、Firefox 等瀏覽器開啟）。
- **方法二（本地伺服器）**：
  若在本地開發環境，亦可在該目錄下執行：
  ```bash
  npx serve .
  # 或
  python -m http.server 8000
  ```
