# 更新日誌 (Changelog)

本專案遵循語意化版本與清晰的變更紀錄原則。

---

## [1.0.0] - 2026-11-13

### 📌 進度摘要
完成教育部國語辭典純前端查詢系統之核心功能開發、字型規格調整、版面修復、本機伺服器腳本整合以及專案狀態與錯誤排解文件的建置。

### ✨ 新增 (Added)
- **純前端核心系統 (`index.html`)**：
  - 建立整合注音（ㄅㄆㄇㄈ）、漢語拼音、多音字標籤、部首筆畫與例句引文的字典頁面。
  - 嚴格落實特定字體大小規格：輸入框 20 點 (`20pt`)、詞語主標題 80 點 (`80pt`)、詞語解釋 20 點 (`20pt`)。
  - 串接教育部國語辭典開放 API（MoEDict CORS 端點），支援正俗體容錯與教育部官方檢索外連。
  - 整合 Web Speech API 提供臺灣國語（`zh-TW`）語音朗讀功能。
  - 內建字卡列印樣式（Print CSS）與剪貼簿複製功能。
- **本機伺服器腳本**：
  - 新增 `server.js`、`package.json` 與 `start.bat`，支援免依賴的輕量本機 HTTP 伺服器與區域網路預覽。
- **專案管理文件**：
  - 建立 `PROJECT_STATE.md`：記錄專案架構、功能實作與狀態清單。
  - 建立 `docs/changelog.md`：記錄專案各版本更新與進度歷程。
  - 建立 `docs/errorsfixed.md`：記錄開發期間遇見之錯誤問題與解決方式。

### 🎨 樣式與視覺調整 (Changed)
- **字型全域指定**：
  - 將全站所有顯示文字統一設定為**標楷體**（優先使用 `DFKai-SB`、`標楷體`、`BiauKai` 等系統內建標楷體字型）。

### 🐛 問題修復 (Fixed)
- **CSS 佈局異常拉伸修復**：
  - 解決因 CSS 選擇器分組造成輸入方塊繼承 `min-height: 100vh` 導致版面垂直異常膨脹問題。
  - 明確設定輸入方塊與查詢按鈕為單行高度 `60px` 垂直置中，並加強行動端響應式版面配置。
